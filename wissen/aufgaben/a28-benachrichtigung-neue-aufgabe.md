# Ziel

Wenn eine neue Aufgabe angelegt wird, muss die KI ist automatisch wahrnehmen können um die Planung durchzuführen. Die Aufgabe wird erst begonnen wenn der Aufgabe eine Aufgaben Nummer zugeteilt wurde im Titel zum Beispiel A{xxx}:Titel, und die Aufgabe geklärt und freigegeben wurde

# Akzeptanzkriterien

- -Wenn eine neue Aufgabe angelegt wird wird die KI benachrichtigt
- -die KI liest die Aufgabe passt den Titel entsprechend an A{xxx}:Titel und wartet auf die Freigabe
- -wenn die Aufgabe freigegeben wurde startet die Umsetzung
