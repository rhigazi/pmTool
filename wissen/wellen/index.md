# Wellen

Jede Welle ist eine eigene Datei in diesem Verzeichnis (`type: Welle`, gemeinsames Statusmodell: Klarung · Offen · In Arbeit · Testing · Dokumentation · Geschlossen; `owner: mensch | ai`). Neue Wellen können über die OKF-Projekt-Manager-App angelegt werden; die Pflege der zugehörigen Aufgaben erfolgt über die Wissensdatenbank.

# Übersicht der Wellen

*Noch keine — die erste Welle (Wave 1: MVP) wird in der Projektplanung angelegt.*
